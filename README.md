# PhishDetect Hub

PhishDetect Hub is a web-based application that helps users detect **phishing URLs** and identify potentially harmful links before interacting with them. It provides a simple and interactive interface to scan suspicious links and view scan history efficiently.

---

## 🚀 Features

- Detect suspicious or phishing URLs
- Interactive and user-friendly dashboard
- Scan history tracking
- Fast and responsive interface
- Clean and modular project structure

---

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Vite

### Tools & Libraries
- ESLint
- PostCSS
- Modern UI components
